# Light Home — лёгкий лаунчер для Яндекс ТВ (DEXP H32G8000C/G)

Свой домашний экран «как Apple TV»: тёмно-синий фон, приветствие, часы и дата слева сверху,
кнопки **Источники / иконка Wi-Fi (открывает Happ; долгое OK — настройки сети) / Настройки** справа, стеклянная панель с приложениями.
Сделан под ваш ТВ: 1 ГБ RAM, интерфейс 1280×720, Android 8–9.

* Только Android framework — **без AndroidX**, без сети, без сервисов, без блюра. Иконки нарисованы кодом.
* Часы обновляются раз в минуту (без постоянных таймеров и TextClock).
* Приложения подхватываются сами (LEANBACK + обычные), избранные идут первыми.
* OK — запуск, **долгое OK** — «О приложении» (остановить/удалить). Источники берутся из системного TvInputManager (HDMI 1/2, ТВ-тюнер).
* Настройки в начале `MainActivity.java`: `COLUMNS`, `FAVORITES`, `HIDDEN_PACKAGES`, `REDUCED_MOTION`.

## 1. Сборка APK (без установки Android Studio)

1. Создайте пустой репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Вкладка **Actions → Build APK → Run workflow**. Через ~3 минуты скачайте артефакт `light-home-apk`.

Локально: JDK 17, Android SDK (platform 34), Gradle 8.9 → `gradle assembleRelease`
(APK: `app/build/outputs/apk/release/`).

## 2. Подготовка ТВ

Настройки → Устройство → О устройстве → 7 раз нажать на «Сборка» → Для разработчиков → **Отладка по USB / ADB** включить.
Нужен `adb` на компьютере в той же сети Wi-Fi/LAN. IP ТВ — в настройках сети.

```bash
export TV_HOST=192.168.1.50        # IP вашего ТВ
tools/scan.sh                      # что установлено и кто ест память (ничего не меняет)
```

Пришлите/посмотрите `tools/scan.txt`, особенно строки `Android:` и список «Кандидаты» —
по ним отредактируйте `tools/packages.txt`. Имена пакетов там — предположения: скрипт пропускает отсутствующие,
но я не видел реальный список пакетов вашего ТВ.

## 2.5. Тест перед установкой (рекомендуется)

**На самом ТВ, безопасно** — лаунчер запускается как обычное приложение, домашним экраном не становится:
```bash
TV_HOST=192.168.1.50 tools/test.sh light-home-apk/app-release.apk
```
Скрипт сохранит `tools/screenshot.png`, покажет расход памяти и ошибки из лога. Home на пульте вернёт штатный лаунчер.

**На компьютере, без ТВ** — Android Studio → Device Manager → Create Device → **Television (720p)** → образ Android 9 (API 28) → запустить и `adb install -r app-release.apk`, затем `adb shell am start -n ru.lighthome/.MainActivity`. Это проверит внешний вид и навигацию, но не поведение YaOS и память вашего ТВ.

## 3. Отключение лишнего и установка

```bash
tools/disable.sh                           # отключает пакеты из packages.txt (обратимо, без root)
tools/install.sh light-home-apk/app-release.apk
```

`install.sh` ставит APK и пробует назначить Light Home домашним экраном. Если YaOS не принял —
нажмите Home на пульте и выберите Light Home → «Всегда». Крайний вариант: `install.sh ... --disable-stock`
(отключает `com.yandex.tv.home`, только когда Light Home уже установлен).

## 4. Откат

```bash
tools/restore.sh      # включает всё отключённое и возвращает com.yandex.tv.home
```
Без компьютера: Настройки → Приложения → включить нужные пакеты.

## Что важно знать

* **Не проверено на вашем ТВ.** Код написан под Android 8–9 по документации; я не мог собрать и запустить его в моём окружении.
  Если что-то выглядит не так — пришлите фото/ошибку, поправим.
* YaOS — закрытая оболочка. Голосовой помощник, умный дом, обновления и часть настроек могут зависеть от `com.yandex.tv.home`
  и сервисов Яндекса. Поэтому по умолчанию отключаются только ivi, Яндекс.Диск и аналитика; остальное — на ваш риск.
* Яндекс-приложения (Кинопоиск, YouTube) могут запускаться как отдельные пакеты — они появятся в сетке сами.
